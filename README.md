Сервис объединяет материалы, планы уроков, задания, проверочные работы, отчёты, файлы и календарь. Для чувствительных материалов предусмотрен отдельный «Сейф» с дополнительной проверкой доступа c помощью пароля.

Реализованные за время хакатона функции:

материалы и личная библиотека;
планы уроков;
задания;
проверочные работы;
шаблоны;
отчёты и редактор отчётных документов;
файлы и вложения;
календарь;
«Сейф» для защищённых материалов и проверочных;
авторизация через MAX Mini App;
адаптивный интерфейс для компьютера и телефона.

## Архитектура

Архитектура включает в себя React+TypeScript (фронтенд). Внешний сервер - Caddy (порты 80/443), внутренний сервер - nginx. Fast API - бэкенд для API, Postgres - БД.

Полный используемый стек:

Бэкенд:

Python 3.12
FastAPI
Pydantic v2
SQLAlchemy 2
asyncpg
Alembic
PostgreSQL 17
PyJWT

Фронтенд:

React 18
TypeScript
Vite 5
nginx


бэкенд-зависимости описаны в `apps/api/pyproject.toml`, фронтенд-зависимости - в `apps/web/package.json` и lock-файле.

Локальный запуск:

```bash
git clone git@github.com:Ubludra/smena.git (на данный момент репозиторий закрытый)
cd smena
cp .env.example .env
docker compose up -d --build
```

По умолчанию локальная конфигурация поднимает  Фронтенд на `http://localhost:5173`, и API на  `http://localhost:8000`
